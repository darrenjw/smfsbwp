### Documentation, models and code relating to the textbook Stochastic Modelling for Systems Biology with Python

This page contains links, code snippets, software and other information relating to the book, Stochastic Modelling for Systems Biology with Python, to be published by Chapman & Hall/CRC, end 2026/early 2027.

The book has ISBN-13 **9781041231509**.
